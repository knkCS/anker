# TruncatedTextCell

Displays a text value on one line. A value wider than its column ends in `…` at the column's edge, and hovering it shows the whole value in anker's `Tooltip`. `maxLength` additionally cuts the value after that many characters, also with a `…` suffix and the whole value on hover. A value that fits shows no tooltip.

Use it for every text value in a `DataTable`: the table clips any cell at its column's edge, so raw text wider than its column is simply cut off, with no `…` and no way to read the rest.

## With Sub-text

The optional `subText` prop renders a smaller muted line below the primary value — useful for "name + creation date", "target + ID", and similar two-line cells. Sub-text is one line too: wider than its column, it ends in `…` and shows whole on hover. It is not affected by `maxLength`.
