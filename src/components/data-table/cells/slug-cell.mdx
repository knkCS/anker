# SlugCell

Displays a slug, handle or code as inline `<code>` text on one line, for easy visual distinction from plain text columns. A value wider than its column ends in `…` at the column's edge, and hovering it shows the whole value in anker's `Tooltip`. A value that fits shows no tooltip.
